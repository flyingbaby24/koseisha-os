# 36 Stratagems Cognitive Bias Atlas

https://www.jinn-project.com/research/stratagems/ (`?lang=ja` / `?lang=en`; one stratagem: `#stratagem-1` … `#stratagem-36`)

For the current Source of Thought runtime architecture, JSON migration status, Rule Framework, and simulator integration, see the [Source of Thought technical architecture index](../source-of-thought/README.md).

```text
docs/research/stratagems/
├── index.html        generated by docs/tools/build-stratagems.mjs — do not edit by hand
├── stratagems.js     the 36 Japanese records and the cognitive tree
├── stratagems-en.js  English translations of the records and the tree
├── i18n.js           UI strings (JA/EN), chapter labels, language helpers
├── atlas.js          board, filters, reader, deep links, language switching
├── style.css         design system
└── fonts/            display-face subset for the stratagem names (SIL OFL)
```

After changing the data, `i18n.js` or the page template, run:

```sh
node docs/tools/build-stratagems.mjs
node --test tests/*.mjs
```

If a stratagem name or chapter label changes, also rebuild the font subset with `site-redesign/tools/build_stratagems_font.py`. Design notes: [`site-redesign/stratagems/`](../../../site-redesign/stratagems/README.md).
