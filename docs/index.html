04About

Four domains, one question.

How do the hidden structures in ideas, bodies, materials and systems become something people can see, play and use? Every Jinn Project work is an attempt at an answer.

  • Thought

    Semantics, cognition and philosophy.

    ThoughtMap · Stratagems Atlas · Source of Thought

  • Body

    Rhythm, movement and perception.

    Mandalizm · Grounding Sole

  • Material

    Land, objects and physical design.

    Kunizukuri · Grounding Sole

  • System

    Open software and public tools.

    JinnSP · ThoughtMap · GitHub

Principles

Inspectable
Research records and source code are public, so results can be checked rather than trusted.
Human-directed
AI accelerates analysis and implementation. Direction and judgement stay human.
Playable
Games and interactive tools are a way to understand ideas, not only to present them.
