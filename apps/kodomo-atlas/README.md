# こどもアトラス

日本全国の出生率と子ども人口を、市区町村・行政区ごとに探索するWebアプリです。React + TypeScript + Vite + Leafletで実装しています。

**実際にダウンロードした公式データを同梱しています。ダミーの人口・出生率、推測による欠損補完は使用していません。**

公開URL：**https://www.jinn-project.com/kodomo-atlas/**

## ローカル起動

Node.js 20.19以上（22以上推奨）とnpmを使用します。このディレクトリで実行してください。

```powershell
npm install
npm run dev
```

ブラウザーで **http://127.0.0.1:5173/** を開きます。同梱データでの起動にはPythonやe-StatのAPIキーは不要です。

```powershell
# 型チェックと本番ビルド
npm run build

# ビルド成果物のローカル配信
npm run preview
```

`dist/` が静的配信できる成果物です。外部の背景地図とGoogle Fontsは任意のオンラインリソースです。フォントが取得できなければシステムフォントを使用し、背景地図をオンにしなくても同梱の行政区域と統計を表示できます。

## 実装済みの機能

- 全国1,896市区町村・行政区をコードで結合し、行政区域を色分け
- 地域名・5桁コードによる検索、都道府県の選択、ドラッグ・ズーム、クリック詳細
- 合計特殊出生率、0〜14歳人口、年少人口比率、子どもの人口密度
- 0〜4歳・5〜9歳・10〜14歳人口、2015→2020年の総人口増減率
- 全国共通の固定区分の凡例、分布ヒストグラム、地域数、欠損数
- 全国値との差、年齢構成、総人口・年齢不詳人口
- 全国・都道府県内ランキング、高い順／低い順、ページ送り、CSV出力
- 2指標の左右比較と移動・ズームの同期
- スマートフォン用の表示設定パネルとレスポンシブレイアウト
- 出典・年度・定義・欠損値を説明するダイアログ

地図は1,902行政区域を収録します。このうち北方地域の6区域には対応する人口統計がなく、欠損色で表示します。統計・ランキングの対象数1,896には含めません。

## データ処理の再現

Python 3.11以上が必要です。初回は国土数値情報のZIP約349MBと統計Excelを取得するため、ネット接続・1.5GB程度の空きディスク・地図の加工に数GBの空きメモリーが必要です。

```powershell
python -m pip install -r scripts/requirements.txt
npm install
npm run data:fetch
npm run data:check
```

- `scripts/prepare_data.py`：公式URLから取得、キャッシュ、統計加工、行政区域の簡略化、コード結合、成果物の生成
- `data/raw/`：ダウンロードした原本と展開したGeoJSON。Git管理対象外
- `public/data/statistics.json`：統計・地図上の位置・定義・元ファイルURL・SHA-256・欠損情報
- `public/data/municipalities.geojson`：市区町村単位に統合した表示用の全国境界（約6.3MB）
- `scripts/validate_data.py`：全国集計値、重複コード、年齢階級の合計、比率・密度、地図との結合、欠損値の検証

キャッシュがあれば再ダウンロードしません。原本も取り直す場合は `npm run data:fetch -- --refresh`、統計だけ加工し直す場合は `npm run data:fetch -- --skip-geometry` を使用します。APIキー不要の公式Excelダウンロードを使っています。

### 結合・集計のルール

1. 都道府県・市区町村コードを**先頭のゼロを保持した5桁の文字列**として扱います。出生率表からは保健所コードを除外します。
2. 国勢調査は男女総数・国籍総数を選び、旧2000年自治体の再掲行を除外します。
3. 政令指定都市は行政区単位、東京都は特別区単位で描画します。20政令指定都市・東京都区部の合計行をランキングに重ねません。市全体の公表値は検索から参照できます。
4. 0〜14歳人口は3階級の公表人数を合計した値です。年齢不詳は補完しません。全国で14,955,692人です。
5. 年少人口比率は**年齢判明人口**を分母とする国勢調査の公表比率を使用します。総人口（年齢不詳を含む）で割り直しません。
6. 子どもの人口密度は0〜14歳人口 ÷ 第1-1表の面積（参考、km²）です。山林等も含む行政区域の全面積による密度で、可住地密度ではありません。
7. 総人口増減率は第1-1表の公表値です。2015年人口は2020年の境域への組替値です。子ども人口の増減ではありません。
8. 全国との比較には出生率・比率・密度・増減率の全国集計値を使います。人口数・年齢別人口は全1,896地域の**単純平均**との差を表示します。人口数で全国総数と市区町村数を比較しません。
9. 国土数値情報に含まれるGeoJSONをコードで統合し、mapshaperで共有境界のトポロジーを保持して120m間隔で簡略化しています。表示用の境界で、測量用途には使えません。未確定境界等は原本の制約を引き継ぎます。

### 欠損値

出生率の次の9町村は、厚生労働省の元表で非公表（`…`）です。`null`のまま保持し、地図では灰色、数値は「—」、ランキングからは除外します。

- 福島県：楢葉町、富岡町、川内村、大熊町、双葉町、浪江町、葛尾村、飯舘村
- 熊本県：球磨村

年少人口比率は1地域、総人口増減率は4地域で算出不可です。ゼロ人口・ゼロ分母等に対して架空の比率を作りません。人数欄の「－」は原表の記号規約に従って0人とし、非公表の「…」と区別します。

出典はアプリ内・GeoJSON由来の地図表示に明記しています。公開・再利用時は各省庁の利用規約に従い、国土数値情報を加工した旨と出典を保持してください。

## GitHub Pagesへの公開

既存の `flyingbaby24/koseisha-os` の `main` ブランチにある `docs/` を使います。独自ドメインやDNSの変更は不要です。

```powershell
cd apps/kodomo-atlas
npm ci
npm run pages:build
```

ソースは `apps/kodomo-atlas/`、静的成果物は `docs/kodomo-atlas/` です。`pages:build` はこのアプリの公開ディレクトリだけを置き換えます。他のプロジェクトはビルド・変更しません。確認済みのソースと成果物を一緒にcommit・pushすると、既存GitHub Pagesが公開します。

本番のVite baseは `/kodomo-atlas/`。統計JSON・GeoJSONの取得とデータ原本へのリンクも `import.meta.env.BASE_URL` に従います。通常の開発サーバーは `/` のままなので、従来のローカル起動とスモークテストを維持しています。`npm run preview` では表示されたホストの `/kodomo-atlas/` を開きます。

公開ディレクトリにはHTML・JS・CSS・統計・境界・アイコン・紹介用の実画面だけを置きます。APIキー、バックエンド、ローカルAPI、開発サーバーは本番動作に不要です。ダウンロード原本やnode_modules、検証用画面は公開対象外です。

## 確認

```powershell
npm run qa:check
npm run data:check
npm run build
```

全国集計との一致、コード結合、政令指定都市と行政区の重複除外、欠損と0、全国公表値、実データのハッシュを確認します。

`npm run dev` を別ターミナルで起動した状態で `npm run qa:browser` を実行すると、独立したGoogle Chromeで8指標・検索・比較・タップ・スマートフォン幅を確認し、`qa/` に結果を保存します。テストは `http://127.0.0.1:5173/` に限定され、外部通信を遮断します。

公開に固有の確認は、リポジトリの `docs/` を `http://127.0.0.1:4173/` で静的配信して `npm run qa:deploy` を実行します。本番反映後は `npm run qa:deploy -- --production` で `https://www.jinn-project.com/` のみを対象に確認します。日英カードからの遷移、直接アクセス・再読込、3市の検索、PC・スマホ比較、ファイルのHTTPエラーとデータのハッシュを確認し、画面を `qa/` に保存します。既存ブラウザーのプロファイルは使用しません。
