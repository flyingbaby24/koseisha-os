# Mandalizm

**Mandalizm** は、音楽と同期して展開する曼荼羅状の波紋を回避しながら、
プレイヤー自身の軌跡によって一枚の曼荼羅を完成させる
**音楽同期型・全方位回避アクション＋空間パズル＋スコアアタック**です。

---

## コンセプト

単なる弾幕回避ゲームではなく、

> **危険を避けた結果そのものが、一曲ごとの曼荼羅として残るゲーム**

を目指しています。

プレイヤーは音楽に合わせて発生する波紋の「門」を通過し、
タイミング・位置精度・移動効率を競います。

## 開発方針

MVPを段階的に実装します。

### MVP 1

- 1曲
- 1プレイヤー
- 円形波紋
- 固定門
- 通常移動
- ワープ
- HP
- スコア
- コンボ
- 曲終了までプレイ可能
- 通過位置への簡易着色

MVP 1が完成するまでは、MVP 2以降の機能は実装しません。

## 開発ルール

- READMEを最初に読む
- 要件定義を仕様の基準とする
- データ駆動設計を優先する
- ScriptableObjectまたはJSONでパターン管理する
- 見た目と判定を分離する
- 調整可能な値はInspectorから変更できるようにする
- Prefab・Sceneで編集可能な構造を維持する
- 実装後はPlay Modeで動作確認を行う

## AI開発者向け

AI（CodeX / Kimi 等）が作業する場合は以下を守ってください。

1. READMEを読む
2. 要件定義を読む
3. 変更対象ファイルを提示する
4. 実装する
5. Play Modeで確認する
6. 要件との差分があれば修正する

コードを書くだけでは完了ではありません。

**実際に遊べる状態であることを完了条件**としてください。
